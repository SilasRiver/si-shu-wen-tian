# 天机阁 · 四术问天

一个纯静态的中国传统术数体验站。四门入局：

| 门 | 模块 | 内容 |
|---|---|---|
| 壹 | **梅花易数** | 年月日时起例（农历正法）、本命卦、数字起卦、字占；本卦 / 互卦 / 变卦三段断，体用生克参月建旺衰；附《周易》六十四卦卦辞与三百八十六爻爻辞原文 |
| 贰 | **八字命盘** | 四柱（立春换年、节气月、五鼠遁）、十神、藏干、五行力量、日主强弱、喜用忌神（扶抑为主调候为辅）、大运九步、一生流年曲线、纳音、旬空、二十类神煞、流年流月流日与择日 |
| 叁 | **MBTI 人格** | 四维八极量表，十六型人格解析 |
| 肆 | **今日运势** | 以日期与生肖为种子，每日一签，同日同生肖结果唯一可复现 |

## 技术说明

- **纯静态**：HTML + CSS + 原生 JavaScript。无框架、无构建工具、无 ES Module、无 fetch/XHR。
  双击 `index.html` 即可离线运行（`file://` 协议下功能完整）。
- **无后端**：全部术数算法在浏览器端计算，不上传任何数据。
- **离线数据**：农历换算与二十四节气用 [solarlunar](https://github.com/yizeze/solarlunar)（MIT）；
  汉字笔画库与一字占拆分表为离线生成的内嵌数据；六十四卦卦辞爻辞取自维基文库《周易》（公有领域古籍）。
- **无素材音效**：全部音效用 WebAudio 实时合成。
